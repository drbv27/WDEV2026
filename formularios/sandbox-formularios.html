Sandbox de Formularios

Clase 10 — bloque 2. Vamos a construir el JS en vivo, zona por zona.

Como funciona: HTML y CSS listos. El archivo sandbox-formularios.js esta vacio. Lo vamos llenando en clase siguiendo la guia. Para cada zona, Ctrl+S + F5 y ven el efecto.

Indice de zonas

  1. Tipos de input + leer valores
  2. Validacion nativa HTML5
  3. FormData — leer todo de una
  4. Mensajes de error en linea
  5. Mini-practica: formulario de registro

1 Tipos de input + leer valores

Un form con todos los tipos juntos. Vamos a leer cada uno desde JS y mostrar el objeto resultante. Cuidado con checkbox/radio (se leen con .checked, no con .value).

2 Validacion nativa HTML5

Atributos required, pattern, min/max, minlength. El navegador valida solo, el CSS aplica :valid/:invalid. Intenta enviar el form vacio o con datos invalidos para ver el mensaje nativo.

3 FormData — leer todo de una

En vez de leer input por input, new FormData(form) los toma todos juntos. Con Object.fromEntries sale un objeto plano listo para enviar al server.

4 Mensajes de error en linea

Cada campo tiene un <small class="error"> debajo. JS escucha el blur y, segun input.validity, muestra el mensaje correcto. Al hacer submit valida todo y enfoca el primer error.

5 Mini-practica: formulario de registro

Combina todo lo de hoy: validacion nativa + estilos visuales + errores en linea + FormData + validacion custom (las dos passwords deben coincidir).
