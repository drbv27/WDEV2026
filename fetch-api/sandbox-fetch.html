6 Axios: la alternativa a fetch cualquier API

Axios es una libreria muy popular para HTTP. Se carga desde CDN. Tiene 3 ventajas grandes sobre fetch: parsea el JSON automaticamente, lanza error en 4xx/5xx (sin tener que chequear response.ok) y maneja mejor configuracion comun (headers, timeouts).
