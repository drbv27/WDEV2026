04

Que es el DOM?

DOM = Document Object Model.

Es la representacion en memoria del HTML, como un arbol de objetos que JavaScript puede leer y modificar.

A partir de este HTML...

<html>
  <body>
    <h1>Hola</h1>
    <p class="intro">JS</p>
    <ul>
      <li>Uno</li>
      <li>Dos</li>
    </ul>
  </body>
</html>
05

... el navegador construye este arbol

document └─ html ├─ head │ └─ title ("Mi pagina") │ └─ body ├─ h1 ("Hola") ├─ p.intro ("JS") └─ ul ├─ li ("Uno") └─ li ("Dos")
Cada etiqueta = un objeto en memoria. Tiene propiedades (texto, clases, atributos) y metodos (cambiar contenido, agregar hijos, eliminarse).
Importante: el DOM no es el archivo HTML. Es lo que el navegador construyo. Si modifican el DOM, el archivo no cambia: solo lo que el usuario ve. Recargar la pagina = vuelve al HTML original.
06

getElementById — el clasico

const titulo = document.getElementById("titulo-principal");
console.log(titulo);              // <h1 id="titulo-principal">
console.log(titulo.textContent); // "Hola"
  • Recibe el id sin el #.
  • Devuelve un solo elemento o null si no existe.
  • El id deberia ser unico en toda la pagina.
  • Es el selector mas rapido y mas viejo. Sigue siendo perfectamente valido.
Cuando usarlo: si tienen un id, usenlo. Punto. No hay que inventar selectores complicados.
07

getElementsByClassName / getElementsByTagName

const items = document.getElementsByClassName("item");
console.log(items);          // HTMLCollection(3)
console.log(items.length);   // 3
console.log(items[0]);       // primer elemento

const todosLi = document.getElementsByTagName("li");
TRAMPA #1: devuelve una HTMLCollection, NO un array.
No tiene .map(), .filter(), .forEach().

NO funciona

items.forEach(...);
// ERROR: forEach no es funcion

Solucion

[...items].forEach(...);
// o Array.from(items).forEach(...)
08

querySelector — el nuevo estandar

Una sola sintaxis para todo. Igual que CSS.

document.querySelector("#titulo-principal");   // por id
document.querySelector(".item");                // primera clase "item"
document.querySelector("li");                   // primer <li>
document.querySelector("ul li.activo");         // CSS compuesto
document.querySelector("input[type='text']");   // por atributo
Devuelve UN solo elemento (el primero que cumple) o null. Si lo saben escribir en CSS, lo saben escribir aqui.
09

querySelectorAll — todos los que cumplen

const items = document.querySelectorAll(".item");
console.log(items);          // NodeList(3)
console.log(items.length);   // 3

items.forEach(i => console.log(i.textContent));  // SI funciona
Devuelve un NodeList, que SI tiene .forEach(). Para usar .map() o .filter() todavia hay que convertirlo: [...nodeList].
Quiero...ClasicoModerno
Uno por idgetElementById("x")querySelector("#x")
Por clasegetElementsByClassName("x")querySelectorAll(".x")
Por taggetElementsByTagName("p")querySelectorAll("p")
CompuestoimposiblequerySelectorAll("ul li.activo")

HTMLCollection vs NodeList

El detalle que confunde a TODOS la primera vez.

HTMLCollectionNodeList
Quien la devuelvegetElementsByClassName
getElementsByTagName		querySelectorAll
Tiene .forEach()NOSI
Tiene .map() / .filter()NONO (convertir con [...])
Es live (auto-actualiza)?SINO (estatica)
Modelo mental:
• HTMLCollection = camara en vivo sobre el DOM. Si el DOM cambia, ella cambia.
• NodeList = foto. Lo que habia en ese momento.

textContent vs innerHTML vs value

const titulo = document.querySelector("h1");

// 1. textContent — texto plano
titulo.textContent = "Hola desde JS";
titulo.textContent = "<b>Hola</b>";  // se ve LITERAL

// 2. innerHTML — interpreta el HTML
titulo.innerHTML = "<b>Hola</b>";     // negrita

// 3. value — SOLO inputs / textarea / select
const input = document.querySelector("#mi-input");
console.log(input.value);        // lo que el usuario escribio
input.value = "valor programatico";
Quiero...Usar
Cambiar el texto de un parrafo/titulotextContent
Insertar HTML (etiquetas dentro)innerHTML
Leer/escribir un input.value
16

Cuidado con innerHTML (XSS)

RIESGO

// Si "mensaje" viene del usuario...
const mensaje = input.value;
contenedor.innerHTML = mensaje;
// Podria inyectar <script> — XSS

SEGURO

// Texto del usuario:
const mensaje = input.value;
contenedor.textContent = mensaje;
// Nunca se interpreta como HTML
Regla de oro: si el texto viene del usuario, usen textContent. innerHTML SOLO cuando ustedes mismos escriben el HTML (template literals controlados por ustedes).
17

classList — el mejor amigo del frontend

const caja = document.querySelector(".caja");

caja.classList.add("activo");       // agregar
caja.classList.remove("oculto");    // quitar
caja.classList.toggle("seleccion"); // si esta la quita, si no la agrega
caja.classList.contains("activo");  // true / false

El patron mas usado del frontend

/* CSS */
.oculto { display: none; }

// JS
boton.addEventListener("click", () => {
    panel.classList.toggle("oculto");
});
Mensaje: mostrar/ocultar paneles, abrir menus, cambiar temas, activar tabs — todo esto es classList.toggle() con una clase CSS. Memoricenla.
18

Atributos: setAttribute / dataset

const img = document.querySelector("img");

img.getAttribute("src");
img.setAttribute("src", "otro.png");
img.removeAttribute("alt");

// Atajo: muchos atributos son propiedades directas
img.src = "otro.png";
img.id = "logo";

data-* — atributos personalizados

<!-- HTML -->
<button data-genero="rock" data-id="42">Rock</button>

// JS
boton.dataset.genero;   // "rock"
boton.dataset.id;       // "42"
Hoy lo van a usar mucho: los botones de filtro de la mega-practica llevan data-genero="...". Es la forma estandar de pegarle informacion a un elemento del HTML para que JS la lea.
19

Estilos: element.style.X

const caja = document.querySelector(".caja");

caja.style.backgroundColor = "tomato";
caja.style.color           = "white";
caja.style.padding         = "20px";
caja.style.borderRadius    = "8px";
caja.style.display         = "none";
Convencion: las propiedades CSS con guion se escriben en camelCase:
• background-color → backgroundColor
• font-size → fontSize
• border-radius → borderRadius
Cuando si y cuando no:
• Para valores dinamicos calculados (barra.style.width = `${porcentaje}%`) → style.X es perfecto.
• Para cambiar la apariencia general → mejor agreguen/quiten una clase y dejen el CSS en el archivo de estilos.
20

Crear elementos: createElement + append

// 1. Crear (todavia NO esta en la pagina)
const nuevoLi = document.createElement("li");

// 2. Configurar
nuevoLi.textContent = "Nuevo item";
nuevoLi.classList.add("item");

// 3. Insertar en el DOM
const lista = document.querySelector("#lista");
lista.appendChild(nuevoLi);

El metodo moderno: append / prepend / before / after

lista.append(nuevoLi);          // al final
lista.prepend(nuevoLi);         // al inicio
lista.append("texto suelto");  // acepta strings
lista.append(li1, li2, li3);   // multiples a la vez

referencia.before(nuevoLi);     // justo antes
referencia.after(nuevoLi);      // justo despues
Importante: hasta que NO lo metemos al DOM, el elemento existe en memoria pero no se ve. Crear no es lo mismo que insertar.
21

Eliminar y reemplazar

// Eliminar
const item = document.querySelector(".eliminar");
item.remove();

// Reemplazar
const viejo = document.querySelector(".viejo");
const nuevo = document.createElement("div");
nuevo.textContent = "Recien creado";
viejo.replaceWith(nuevo);

// Vaciar un contenedor
contenedor.innerHTML = "";
TRAMPA #2: contenedor.innerHTML += "<li>..."
Se ve comodo. Pero borra y reconstruye TODO el contenido del contenedor. Si dentro habia inputs con texto escrito, se pierden. Si habia event listeners, se rompen.
Excepcion util: cuando van a vaciar y volver a pintar de cero (como en la funcion renderizar que veremos ahora), innerHTML = "" seguido de pintar todo de nuevo esta perfecto.

Mega Practica: catalogo de canciones

Vamos a tomar canciones-rock.js y renderizarlo en una pagina real, con buscador y filtros.

1️⃣

Pintar 10 tarjetas

Crear el HTML de cada cancion con createElement + innerHTML.

2️⃣

Funcion renderizar

Una funcion renderizar(lista) que limpia y repinta.

3️⃣

Buscador en vivo

Input + filter + repintar en cada letra.

4️⃣

Filtros por genero

Botones con data-genero y clase activo.

Mensaje: esta practica une lo de HOY (DOM) con lo de las clases 5-7 (filter, map, objetos). El DOM es solo un destino para los datos que ya saben manipular.
24

Fase 1 — Pintar las primeras 10

const contenedor = document.querySelector("#grid-canciones");
const primeras10 = canciones.slice(0, 10);

for (const cancion of primeras10) {
    const tarjeta = document.createElement("div");
    tarjeta.classList.add("tarjeta");
    tarjeta.innerHTML = `
        <h3>${cancion.titulo}</h3>
        <p class="banda">${cancion.banda}</p>
        <p class="anio">${cancion.anio}</p>
    `;
    contenedor.appendChild(tarjeta);
}
Mezcla: slice (clase 5) + for ... of (clase 3) + createElement/innerHTML (hoy) + template literals (clase 2). Esto es codigo profesional.
25

Fase 2 — Funcion renderizar(lista)

function renderizar(lista) {
    contenedor.innerHTML = "";            // limpio

    if (lista.length === 0) {
        contenedor.innerHTML = "<p class='vacio'>No hay canciones</p>";
        return;
    }

    for (const cancion of lista) {
        const tarjeta = document.createElement("div");
        tarjeta.classList.add("tarjeta");
        tarjeta.innerHTML = `
            <h3>${cancion.titulo}</h3>
            <p class="banda">${cancion.banda}</p>
            <p class="anio">${cancion.anio}</p>
            <span class="genero">${cancion.genero}</span>
        `;
        contenedor.appendChild(tarjeta);
    }
}

renderizar(canciones);
Mensaje pedagogico: una sola funcion que recibe una lista y la pinta. Esta es la idea central de React: UI = funcion(datos). Hoy la entienden desde la base.
26

Fase 3 — Buscador en vivo

<!-- HTML -->
<input type="text" id="buscador" placeholder="Buscar..." />

// JS
const buscador = document.querySelector("#buscador");

buscador.addEventListener("input", () => {
    const texto = buscador.value.toLowerCase();

    const filtradas = canciones.filter(c =>
        c.titulo.toLowerCase().includes(texto) ||
        c.banda.toLowerCase().includes(texto)
    );

    renderizar(filtradas);
});
Dato real: esto es filtrado reactivo en tiempo real, en 5 lineas. Cada vez que escriben en YouTube, Spotify, Mercadolibre o Rappi, esto es lo que pasa.
27

Fase 4 — Filtros por genero

<!-- HTML -->
<div class="filtros">
    <button data-genero="todos" class="activo">Todos</button>
    <button data-genero="hard rock">Hard Rock</button>
    <button data-genero="power ballad">Baladas</button>
</div>
const botones = document.querySelectorAll(".filtros button");

botones.forEach(btn => {
    btn.addEventListener("click", () => {
        botones.forEach(b => b.classList.remove("activo"));
        btn.classList.add("activo");

        const genero = btn.dataset.genero;
        const lista = genero === "todos"
            ? canciones
            : canciones.filter(c => c.genero === genero);
        renderizar(lista);
    });
});
Combo de hoy: querySelectorAll + classList.remove/add + dataset.genero + filter + renderizar(lista). Un filtro tipo Spotify en 12 lineas.
